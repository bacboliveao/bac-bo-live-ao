# BAC BO LIVE AO

Protótipo inicial de uma plataforma web responsiva para consulta de indicadores e registos estatísticos de Bac Bo.

## Como visualizar
Abra `index.html` num navegador.

## Publicação
Este projecto pode ser publicado como site estático. Os dados actuais são apenas demonstrativos; não existe ligação a uma fonte de dados em directo.
